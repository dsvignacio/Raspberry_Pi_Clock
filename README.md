# RaspiAnalogDigitalClock

This project is a simple, elegant analog and digital clock designed to be displayed on a Raspberry Pi with a 7-inch touchscreen. It's built with plain HTML, CSS, and JavaScript, with no external dependencies besides what's included in the repository.

## Project Overview

The main purpose of this application is to provide a clear and easy-to-read clock face, suitable for a dedicated display like a Raspberry Pi touchscreen. It features both an analog clock with moving hands and a digital clock displaying the time and date.

## Features

*   **Analog Clock**: A classic clock face with hour, minute, and second hands.
*   **Digital Clock**: Displays the current time (HH:MM:SS AM/PM) and date.
*   **Fullscreen Mode**: A button to toggle fullscreen mode for an immersive experience.
*   **Lightweight**: Built with vanilla HTML, CSS, and JavaScript, making it fast and easy to run.
*   **Customizable**: The styling can be easily modified in the `css/main.css` file.

## Setup

To run this project, you don't need any special build process or package manager.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/RaspiAnalogDigitalClock.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd RaspiAnalogDigitalClock
    ```
3.  **Open `index.html` in your web browser:**
    You can simply open the `index.html` file directly in a web browser like Chrome, Firefox, or Safari.

## Usage

Once you have the `index.html` file open in your browser, the clock will start running automatically.

*   The **analog clock** is displayed in the center of the page.
*   The **digital clock** is displayed below the analog clock.
*   The **fullscreen button** (a square icon) will appear in the top right corner if your browser supports the Fullscreen API. Click it to enter or exit fullscreen mode.

This project is designed to be run in a browser on your Raspberry Pi, but it will work on any modern web browser.
